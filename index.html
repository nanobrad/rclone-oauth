Personal Rclone Drive Sync

Welcome to the application portal for Personal Rclone Drive Sync. This application provides a dedicated Google Cloud OAuth 2.0 client configuration used exclusively to synchronize, back up, and mount personal Google Drive files to local systems via the open-source command-line tool Rclone.

🔒 100% Client-Side

Operates entirely on the local client machine. There are no hosted intermediary web servers or proxy databases.

⚡ Direct Google API Connection

Network requests travel directly between the local Rclone binary and official Google Drive API endpoints via HTTPS.

🛡️ Local Token Storage

All authentication tokens and refresh credentials remain strictly confined to the local user configuration file.

Google OAuth Verification & Policy Notice:

This application complies with the Google API Services User Data Policy, including the Limited Use requirements. Please review our full legal disclosures below.
