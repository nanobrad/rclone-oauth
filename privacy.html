Privacy Policy

Last updated: October 14, 2026

1. Overview

This Privacy Policy explains how Personal Rclone Drive Sync ("the Application", "we", "us", or "our") handles user data when interacting with Google APIs, specifically the Google Drive API.

The Application is an individual, self-hosted integration enabling the open-source software Rclone to access Google Drive storage on behalf of authorized users for personal backups, directory synchronization, and local filesystem mounting.

2. What Information We Access

When you authorize the Application through Google's OAuth 2.0 flow, Rclone requests permission to interact with your Google Drive account. Depending on your configuration, this may include:

  • Google Account Identifier: Basic account email used strictly to verify the identity of the authenticating user during the OAuth consent flow.
  • Google Drive Files and Metadata: File contents, folder hierarchies, timestamps, file sizes, and MIME types necessary to perform requested read, write, copy, move, sync, or mount actions.
  • OAuth Authentication Tokens: Temporary access tokens and persistent refresh tokens issued directly by Google to authorize subsequent API requests.

3. How Information is Used and Transferred

All data retrieved from Google Drive is used strictly and exclusively to fulfill the local operations requested by the user:

  • Direct file transfer between your local device and Google Drive servers.
  • Local virtual filesystem mounting via FUSE.
  • Integrity verification (checksums and hashes) between local files and remote copies.

No Intermediary Servers: Communication occurs directly between the Rclone client running on your machine and Google’s official API endpoints (https://www.googleapis.com). No telemetry, usage statistics, user data, or file payloads are ever routed through or uploaded to any third-party or hosted server.

4. Data Storage and Security

  • Local Storage Only: All OAuth tokens (access tokens and refresh tokens) and configuration parameters are stored locally on your machine in Rclone's configuration file (by default, ~/.config/rclone/rclone.conf).
  • Encryption: Rclone provides built-in configuration encryption to protect tokens stored at rest. We strongly recommend encrypting your local configuration file.
  • No Cloud Retention: We operate no external databases, tracking systems, log collectors, or cloud analytics services.

5. Data Sharing and Third Parties

We do not sell, rent, lease, trade, transfer, or disclose your personal data or Google Drive contents to any third parties. Your data is neither used for advertising, nor used to train artificial intelligence or machine learning models.

6. Google API Services User Data Policy Compliance

Limited Use Requirement:
Personal Rclone Drive Sync's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. How to Revoke Access

You retain full control over your Google account permissions at all times. You can revoke this application's access immediately by:

  1. Visiting your Google Account settings: Google Account Third-Party Permissions.
  2. Locating Personal Rclone Drive Sync in the list of authorized third-party apps.
  3. Clicking Remove Access.

Additionally, you may delete your local configuration at any time by removing the remote from your local rclone.conf file via rclone config delete [remote_name].
